# Specification: Runtime Packaging and Hermes Validation

Package benchmark-promoted adapters for practical local use through MLX, Ollama, LM Studio, and Hermes. Document the runtime card template, endpoint smoke matrix, and SSD artifact policy alongside the packaging flow.

Acceptance criteria:

- Runtime smoke passes.
- Artifacts stay off Git.
- Endpoint and commands are documented.
- Runtime card template captures runtime, command, endpoint, smoke prompt, result, and limitations.
- MLX server, Ollama, and LM Studio fallback commands are documented.
- Endpoint smoke matrix and SSD artifact policy are documented.
